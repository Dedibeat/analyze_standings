# NUM-R^3 team solves around 2400

The team observed that most virtual and official solves were below 2400. Joined the recorded in-contest outcomes to the shipped hierarchical fit on contest ID and problem label, including the 2026 Shenyang board. The participation export's embedded ratings predate this model. Classified problems before rounding. The [HK plan](../reports/team-r3/hong-kong-2027.md) now uses the observed team bands for weekly upsolves and mock review.

Of 89 in-contest ACs across 17 rounds, 84 have a shipped rating. Of these, 78 were below 2400 and six were at least 2400. The latter were virtuals 1794 C (2428.9), 2524 J (2576.3), 4607 H (2578.0), 1071 G (2602.4), 1794 L (2680.4, GPT-assisted) and 1071 I (2788.8). Removing the documented assisted AC leaves 5 of 83 rated ACs at 2400+. All five unrated ACs came from 2575. The 72/72, 6/9, 3/14 and 3/110 rates in the plan count every rated problem offered in its respective band. Unknown effort on skipped tasks limits their use as estimates of selection-conditioned practice success.

The three official rounds had 15/15 below 2400 and 0/24 above or equal. At the previous HK seat-replay lines the three solved problems were rated 955.8, 1658.3 and 2304.8 (2024) and 1007.5, 2028.6 and 2155.9 (2025). The latter line was a two-team tie. No model refit or data refresh was needed.

## Reproduce from the repository root

```bash
python3 - <<'PY'
import csv
import json
from collections import Counter

def load(path):
    with open(path) as f:
        return json.load(f)

ratings = {(p["contest_id"], p["problem_label"]): p["difficulty_cf"]
           for p in load("output/problem_ratings_hier.json")}
rounds = [(r["kind"], r["contest_id"], [p["label"] for p in r["problems"]], set(r["solved"]))
          for r in load("output/team_r3_participations.json")]
sy = next(b for b in load("data/xcpcio_51st_regionals.json") if b["board_link"].endswith("/shenyang"))
team = next(r for r in sy["standings"] if r["team_name"] == "NUM-R^3")
rounds.append(("official", sy["contest_id"], [p["problem_label"] for p in sy["problems"]],
               {k for k, p in team["problems"].items() if p["solved"]}))

counts = Counter()
for kind, cid, labels, solved in rounds:
    for label in labels:
        rating = ratings.get((cid, label))
        band = "unrated" if rating is None else next(b for b in (2300, 2400, 2600, float("inf")) if rating < b)
        counts[kind, band, "offered"] += 1
        counts[kind, band, "AC"] += int(label in solved)
        if rating is None:
            continue
        if (label in solved and rating >= 2400) or (label not in solved and rating < 2400):
            print(kind, cid, label, rating, "AC" if label in solved else "miss")
for kind in ("virtual", "official"):
    for band in (2300, 2400, 2600, float("inf"), "unrated"):
        print(kind, band, counts[kind, band, "AC"], "/", counts[kind, band, "offered"])

boards = {b["contest_id"]: b for b in load("data/tagged_official.json")}
with open("data/ec_online/regional_teams.csv") as f:
    hk = [r for r in csv.DictReader(f) if r["site"] == "hongkong"]
for season, cid, rank in (("2024", 1885, "37"), ("2025", 3169, "32")):
    for r in hk:
        if (r["season"], r["official_rank"]) == (season, rank):
            row, = (t for t in boards[cid]["standings"] if t["team_name"] == r["team"])
            print(season, rank, r["team"], sorted(ratings[cid, k] for k, p in row["problems"].items() if p["solved"]))
PY
```
