# Competitive programming problems for tutorial videos

Selected 21 problems for viewers learning divide and conquer (5), greedy (6),
recursion (5), and dynamic programming (5). The request prioritized a memorable
discovery and a short, unambiguous proof. Each entry in the
[teaching guide](../teaching/tutorial_video_problems.md) includes a source,
an opening question or demonstration, and a correctness argument.
The first entry in each section is the suggested opening episode.

To list the selections by topic, run
`rg "^#{2,3} " docs/teaching/tutorial_video_problems.md`.
