### G. Game — field 1060 — **AC 137.5' after 1 MLE** (Dedi)
- **Idea:** draws are irrelevant (p0 = a0/(a0+a1)). The game is a subtraction Euclid. Accelerate
  with division: k consecutive wins by the same side form a geometric series. O(log). Tags:
  probability, Euclid.
- 2924634 (100.9') MLE: the recursion explores **both** outcomes as separate calls
  (`self(self, x, y - x, …); self(self, x - y, y, …);`): an exponential tree of subtraction steps.
  2925113 (137.5') replaces runs of the same outcome with a geometric-series sum
  (`g(a, b, k)`) and `x % y` → AC.
- 37 minutes from MLE to AC. The first version should have been rejected on paper: x = 1, y = 10^9
  means 10^9 subtraction steps.

### L. 502 Bad Gateway — field 953 — **AC 86.5' after 3 wrong runs** (Dedi)
- **Idea:** the optimal strategy is a threshold c: keep resetting until the value is < c. The
  expected time (c−1)/2 + T/c is a "tick" function, minimised at ⌊√(2T)⌋ or ⌈√(2T)⌉. Fractions plus gcd.
  O(log T) per test. Tags: expectation, convexity.
- **Attempts:**
  1. 2924110 (62.0') WA: the right expected-value formula, but the threshold was **guessed** as
     `L = min((n + 2) / 2, n)` instead of being minimised.
  2. 2924396 (84.0') WA: **byte-identical** to the first run (994 bytes, empty diff). A wrong file
     was submitted or the same code was resubmitted.
  3. 2924407 (84.8') TL: binary search on the convex function, with `__gcd` called inside every
     comparison. With 10^6 tests that is about 6·10^7 gcds.
  4. 2924434 (86.5') AC: gcd only once, at the end.
- **Lessons:** minimise instead of guessing (the function is convex; √(2T) comes from the
  derivative). **Never resubmit without a diff.** Keep expensive operations out of inner loops
  when T = 10^6.
