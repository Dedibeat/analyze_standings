## Problems

### A. Modulo Ruins the Legend — field 301 (QOJ) — **AC 100.6' after 1 WA** (Dedi)
- **Idea:** adding an arithmetic progression = adding n·s + n(n+1)/2·d, so minimise
  (S + n·s + n(n+1)/2·d) mod m via gcd(n, n(n+1)/2, m). Extended Euclid gives s, d. Tags: number
  theory (ext-gcd, linear congruences).
- 3079601 (83.8') WA: `egcd(g, m, invg, tmp)` returns a **negative `invg`** that was used directly
  (`int t = (R / gg) * invg % m;`). 3079804 adds `invg = (invg % m + m) % m;` (plus a brute force
  and a tester) → AC.
- **Bug class:** negative values from ext-gcd and `%` in C++. A library `modinv`/`crt` that always
  returns [0, m) removes it.

### C. No Bug No Game — field 299 (QOJ) — **AC 167.1', first try** (Erdene)
- **Idea:** if Σp ≤ k take everything. Otherwise exactly one item is partially upgraded: knapsack
  f[j][t] with t ∈ {0,1} for "the partial item already used". O(n·k·p). Tags: knapsack DP.
- **Ours:** 3080592 is exactly the editorial's first solution (`dp[j][1] = max(dp[j][1],
  dp[j - c][0] + w[c])`). Clean.

### D. Money Game — field 626 — **AC 18.4' after 1 WA** (Erdene)
- **Idea:** it converges to 2w, w, …, w with w = S/(n+1).
- 3078780 WA: simulated 100 rounds (`rep(j, 0, 100)`), which is not enough for large n.
  3078829 uses the closed form → AC. **Lesson:** "simulate until it converges" needs a convergence
  argument. Printing the sample after more rounds would have shown the pattern.

### G. Subgraph Isomorphism — field 78 (QOJ) — **AC 173.6' after WA, MLE** (idea Tamir, implementation Dedi)
- **Idea:** tree → YES; more than one cycle → NO; exactly one cycle → the rooted trees hanging off
  the cycle must be all equal (aaaa) or alternate (abab, even length). Compare them by tree hashing
  or canonical forms. Tags: graph structure, tree isomorphism.
- **Ours:** AHU canonical form via `map<vector<int>,int>` and the aaaa/abab check, i.e. the
  editorial's method.
- **Attempts:**
  1. 3080341 (142.8') WA: the cycle walk was `int cnt = 100; while(y != x && cnt--)`, a **debug cap
     left in** that truncates cycles longer than 100.
  2. 3080624 (169.7') MLE: changed the back-edge detection (`d[v] < d[u]`) and removed the cap. The
     new detection was wrong and the walk never terminated.
  3. 3080668 (173.6') AC: the original detection with `cnt = 1e18`, i.e. only the cap removed.
- **Lesson:** the same bug class as 2661 J (`l < 3`): a test-time limit shipped in the submission.
  The pre-submit checklist must include "search for debug caps and test-only constants".

### I. Guess Cycle Length — field 35 (QOJ) — **AC 275.4', first try** (Erdene)
- **Idea:** 3333 random walks give a lower bound m on n (the maximum label seen); then baby-step and
  giant-step walks (3333 steps of 1, one step of m, 3333 steps of 3333) find a repeat. Tags:
  interactive, randomization, BSGS.
- **Ours:** 3081325 is exactly the editorial's plan. A first-try solve of a hard interactive problem:
  **Erdene's interactive skill again** (cf. 4607 H).
- The three later I runs (292–299', after the AC) tested variants. Harmless for the score, but they
  took attention away from M in the last minutes.

### K. Master of Both — field 281 (QOJ) — **AC 50.6', first try** (idea Dedi, implementation Tamir)
- **Idea:** insert the strings into a trie and count, for each letter pair (x, y), the pairs whose
  first difference is x vs y (plus prefix pairs). Each query sums cnt[b][a] over pairs with a < b in
  that alphabet. O(26·Σ|s| + 26²·q). Tags: trie, counting.
- **Ours:** 3079239 is exactly that (`pre[k][j] += root->child[j]->cnt`, with a sentinel character
  for prefixes). 35 minutes faster than the median: an excellent pair solve.

### M. Please Save Pigeland — field 34 (QOJ) — **failed (2 runs; the QOJ board counts 1)** (member not recorded)
- **Idea:** d = gcd of distances from the root r. Minimise Σdist / gcd over r with rerooting DP,
  keeping each distance set as (first element f, gcd of differences g) so that "add w to all" and
  "merge" are O(log). Tags: tree DP (rerooting), gcd.
- **Ours:** 3081369 is the editorial's rerooting structure (`stt = {sum, cnt, mn, g}`, `merge`,
  `add`, prefix and suffix merges). 3081379 is the **identical file resubmitted** 3 minutes later.
  Not debugged here: it was the 8th problem, attempted with 17 minutes left.
