## Problems

### A. Cipher — field 69/260 (cf 2445) — not attempted (no code)
- **Idea:** smallest x with a^x ≡ b (mod 2^64). Even a: only x ≤ 64 matters. Odd a: the order is a
  power of two, and ctz(a^{2^k} − 1) strictly increases, so build x bit by bit (fix bit
  ctz(a^{2^k}−1) by multiplying by a^{2^k}). O(log² V). Tags: number theory (discrete log
  mod 2^k), bits.
- **Why missed:** the standard 5th problem. A number-theory "discrete log mod 2^64" looks scary,
  but it is a known lifting trick. **Question:** was A read in the last 85 minutes?

### C. Finding Keywords — field 259/260 (cf 1023) — **AC 31.4', first try** (Dedi)
- **Idea:** f_0 = ∞, f_i = number of partial matches of length i. Value b_p moves one from f_{p−1}
  to f_p. O(Σl). Tags: greedy.
- **Ours:** 3150797 is exactly the editorial's second method (`dp[0] = 1e9; … dp[i + 1]++;
  dp[i]--;`). Correct; 17 minutes slower than the gold median.

### E. Tree and Subgraph Problem — field 52/260 (cf 2522) — not attempted
- Count pairs of same-color sets with disjoint Steiner trees via Σg_e − Σf_v (edges minus vertices on
  the separating path), with inner/outer counts by DSU on tree. Mid-hard counting. A 6th-problem
  candidate.

### F. Grid Filling Game — field 116/260 (cf 2320) — **AC 215.2' after 2 WA** (Dedi)
- **Idea:** intervals of length ≥ 3 and disjoint neighbours split the line into independent pieces.
  Inside a piece (lengths 1–2), check whether an alternating choice avoids all equalities; otherwise
  exactly one length-2 block is forced. A single 2-interval between two 1-intervals joins the
  shorter neighbouring run (greedy). O(n). Tags: greedy, casework.
- **Ours:** the editorial's segmentation-plus-greedy, in our own form (`check(L, R, cur)` and
  joining the shorter neighbour: `if(seg[i - 1][3] <= seg[i + 1][3])`).
- **Attempts:**
  1. 3152894 (176.4') WA: **inverted boolean**: `s = ok;` where `check` returns 0 when a collision
     is forced, so the cost should be `ok == 0`.
  2. 3153295 (203.7') WA: `s = 1 - ok;` fixed it, but `check` ignores intervals that are neither
     single nor length-2. A wide interval must break the forced chain.
  3. 3153450 (215.2') AC: `else sing = 0;` added. An empty `// int brute(...)` stub shows a
     brute force was started but not written.
- **Lesson:** both bugs are visible on 4–5-element random tests against a brute force over tiny
  values. The stub was there; writing it first would likely have saved silver.

### K. Card Game — field 229/260 (cf 1940) — **AC 116.6', first try** (Tamir)
- **Idea:** the answer is 1 iff Alice's first card is one Bob lacks, else 0. Construction: for each
  value Alice holds twice, Bob plays one of his own pairs just before her two copies. Tags:
  constructive game.
- **Ours:** 3151919 builds exactly that (Bob's double values `b`, assigned at `ans[i - 1]` and
  `ans[r[a[i]] - 1]`). Correct first try. 50 minutes behind the gold median: the proof took time.

### L. Activity Rehearsal — field 207/260 (cf 2016) — **AC 82.4', first try** (Erdene)
- **Idea:** the item put back in round i is a_{n+i} = min(a_{2i−1}, a_{2i}), so the dependencies form a
  segment-tree-shaped DAG. A swap changes O(log n) rounds; keep the selected values in a Fenwick or
  segment tree. O(m log² n). Tags: data structures, structure discovery.
- **Ours:** 3151375 is exactly this (`p[i*2-1] = p[i*2] = i + n`, walk up `while(p[cur] != 0)`,
  segment tree of maxima). It handles the swap as three passes (x := 0, set y, set x) to avoid stale
  values. Faster than the gold median (82' vs 90'): a strong solve.
