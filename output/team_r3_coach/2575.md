## Problems

### A. k-subset-sum GCD (Another GCD Problem) — field 249/260 — **AC 34.9'** (CE first)
- **Idea:** f(k) = gcd(k·a_1, a_2−a_1, …, a_n−a_1). The answer is g = gcd of the differences and the
  smallest k = lcm(a_1, g)/a_1. "infinite" iff all elements are equal. Tags: number theory.
- **Ours:** 3253103 is exactly that (`int k = g / gcd(g, a[0]);`). 3253098 was the same file
  submitted as **C++14**, where `std::gcd` does not exist → Compile Error (no penalty, 1 minute).
- **Fix:** set C++20 as the default language at the start of every contest.

### B. Hydraulic press (Ball And Movable Walls) — field 74/260 — not attempted
- **Idea:** treat x and y separately. y gives the end time T. In x, the bounces off the moving walls
  are O(log T) because each bounce lengthens the path by ≥ 1/20, so simulate them. Tags: simulation,
  physics/geometry. Statement guarantees make it safe. The 7th problem for many 6-solvers (ABGIKL ×18).

### C, D, E, F — field 3, 0, 0, 2 /260 — not attempted. Correct skips.

### G. Snow sweeping (Great Snowfall) — field 234/260 — **AC 54.1', first try**
- **Idea:** greedy top-left to bottom-right. A row is fixable iff its sum is 0 and every prefix sum is
  ≥ 0. Push surplus down, pay for deficits. O(nm). Tags: greedy.
- **Ours:** 3253244 carries the per-column surplus down and covers each deficit from the right-most
  surplus with a priority queue, O(nm log m). Correct, slightly heavier than the O(nm) suffix-min
  version.

### H. Matching (How Many Rounds Are Expected?) — field 9/260 — not attempted. Correct skip.

### I. Hexagon flip (Infinite Hexagonal Grids) — field 131/260 — **not attempted; should have been the 5th problem**
- **Idea:** YES iff for every x-line, y-line and z-line the parity of black cells is the same in both
  pictures. Each operation flips exactly two cells on every coordinate line, and the converse holds
  by peeling the outer hexagon ring. Implementation: count parities with maps. ~20 lines. Tags:
  invariant/parity, observation.
- **Why we probably missed it:** an invariant problem with a picture and 3-D hex coordinates *looks*
  heavy, but the code is trivial once the parity invariant is guessed. The field solved it at gold
  median 120' (before J). Reading order or a quick "check small cases for an invariant" pass would
  have caught it. **Question:** was I read, and by whom?

### J. Judge of Gensokyo (mirror palindrome) — field 80/260 — **AC 260.7' after WA, MLE, MLE**
- **Idea:** expand w→vv, run Manacher, and for each center shrink the ends past split w's to get a
  substring that exists in s. O(|s|), with |s| ≤ 10^7 in total. Tags: strings, Manacher, casework.
- **Attempts:**
  1. 3255345 (221') WA: the shrink casework was off by one (`int d1 = suf[l] - l + 1;`,
     `add(l + d + 1, r - d - 2);`). It also missed all-w substrings.
  2. 3255653 (252.8') **Memory Limit**: fixed the casework, using a brute force plus random tester
     (`brute`, `test(100000, 10)`) and adding `for(...) if(s[i]=='w') add(pre[i], i);`. But it
     materializes `vector<array<int,4>> pal` for ~4n centers with `#define int long long`, plus
     `vector<pair<ll,ll>> v` and the 4n-character `u`. For n = 10^7 that is several GB.
  3. 3255683 (255.9') removed `#define int long long`; still MLE (866 MB).
  4. 3255722 (260.7') processes centers on the fly instead of storing `pal` → AC at **620 MB /
     906 ms**.
- **Lessons:** (a) with n = 10^7, estimate memory *before* coding: every 8-byte array of 4n is
  320 MB. (b) The brute-force tester again found the logic bug (good), but only after a WA.

### K. 0/1 knapsack greedy breaker (Knapsack And Greedy Algorithm) — field 227/260 — **AC 125.7', first try**
- **Idea:** the unique construction has weights 1, n, n−1, …, 2 and values n, n²−1, n²−n−2, …,
  n+1. Tags: constructive, proof by induction.
- **Ours:** 3254164 produces exactly the editorial values (`v[i] = (i+1)*n - (n-i)`). The unused
  `rec()` and `b` scaffolding shows the pattern was found by experiment. Good.

### L. Grid obstacle avoidance (Let's Avoid Obstacles) — field 218/260 — **AC 114.1' after 3 WA**
- **Idea:** for each of the 2^k masks, sweep columns: move right, block the forbidden cells, relax up
  and down. O(nm·2^k). Tags: DP/BFS, bitmask enumeration.
- **Attempts:**
  1. 3253723 (94.6') WA, **sentinel arithmetic**: `const int inf = 2e18;` plus
     `else if(dp[i][j - 1] != -1) dp[i][j] = dp[i][j - 1] + 1;`. Unreachable cells become
     inf+1, inf+2, …, which later fail `== inf` tests, and the final `ans == inf ? -1 : ans` prints
     garbage.
  2. 3253747 (96.5') WA, **blind guess**: reversed the obstacle-to-bit order (`int id = k - 1; …
     id--;`) two minutes later. The statement defines the order explicitly (low bit = obstacle 0).
  3. 3253823 (101.3') WA: in the vertical pass a blocked cell does `val++; continue;`. The running
     value then crosses the obstacle, so paths go *through* blocked cells.
  4. 3254018 (114.1') AC after a rewrite: `inf = 1e9`, explicit blocking loops, then
     `dp[i][j] = min(dp[i][j], dp[i-1][j] + 1)` that never overwrites blocked cells, and
     `ans >= inf/2 ? -1`.
- **Lesson:** the third consecutive contest with a sentinel/overflow bug (cf. 4593 C, 4607 D). Use a
  moderate INF (1e9 for distances, 4e18 only when really needed). Never compare to a magic value
  that arithmetic can drift away from. Test `>= INF/2`.
- Style note (not evidence of authorship): attempts 1–3 use lambda-style code and commented-out
  debug prints; the AC is a rewrite in a different brace style. Two people may have handled it.

### M. Connected equilateral triangles — field 21/260 — not attempted
- Counting with conditions i+j ≥ n etc. and i+j+k ≠ 2n, suffix sums. Mid-hard counting; fine skip
  at our level for this contest.

## Takeaways from this contest
1. **Triage, not ability, cost the silver.** I (131 official solves, parity invariant, ~20 lines) was
   skipped while 95 + 40 minutes went into J (80 solves, intricate casework and 10^7-size memory).
2. **Sentinel bugs again (L)** and **memory not estimated for n = 10^7 (J)**: 5 of 6 wrong runs.
3. **A blind resubmission** with a flipped bit order (L #2) wasted a penalty: re-read the
   statement's numbering instead.
4. **Compile error from the default language** (C++14).
5. **Strengths:** a clean constructive (K) and greedy (G), both first try. The brute-force tester
   habit appears again (J).
