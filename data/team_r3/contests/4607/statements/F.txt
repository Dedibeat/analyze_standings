F

First Word

Time limit: 5s

VegiCat has a string S of n lowercase English letters. He wants to build a dictionary
that contains k distinct nonempty substrings of S as its words. A substring is a
contiguous part of a string. Substrings with the same content are treated as the same
word, even if they occur at diﬀerent positions in S.
Let π be a mapping from the letters a, b, . . . , z to the corresponding letters in a
permutation of the 26 lowercase English letters. For example, the permutation
qwertyuiopasdfghjklzxcvbnm deﬁnes the following mapping:
c a b c d e f g h i j k l m n o p q r s t u v w x y z
π(c) q w e r t y u i o p a s d f g h j k l z x c v b n m

For a string u = u1 u2 · · · um , deﬁne

π(u) = π(u1 )π(u2 ) · · · π(um ).

For example, with the mapping above, π(apple) = qhhst.
VegiCat wants the dictionary to contain a word w such that, after applying any such mapping π to every word
in the dictionary, π(w) is always the lexicographically smallest word in the resulting dictionary.
For each k = 1, 2, . . . , n, ﬁnd the number of dictionaries that contain k distinct words and satisfy the requirement,
modulo 998244353. Two dictionaries are considered diﬀerent if and only if they contain diﬀerent sets of words
before any mapping is applied.
Recall that string a is lexicographically smaller than string b if a is a preﬁx of b (and a ̸= b), or there exists an
index i (1 ≤ i ≤ min(|a|, |b|)) such that ai < bi , and for any index j (1 ≤ j < i) aj = bj .

Input
The ﬁrst line contains an integer T (1 ≤ T ≤ 104 ), the number of test cases. The description of the test cases
follows.
The ﬁrst line of each test case contains an integer n (1 ≤ n ≤ 105 ).
The second line contains a string S of length n, consisting only of lowercase English letters.
It is guaranteed that the sum of n over all test cases does not exceed 105 .

Output
For each test case, output n integers on one line. The k-th integer represents the number of dictionaries that
contain k distinct words and satisfy the requirement, modulo 998244353.
