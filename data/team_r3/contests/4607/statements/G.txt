G

Graph Reconstruction

Time limit: 2s

VegiCat has an n × n integer matrix A = (aij ). For each 1 ≤ i, j ≤ n:
• If i = j, i = 1, or j = 1, then aij = −1.
• Otherwise, aij is a nonnegative integer.
Help VegiCat construct an undirected simple graph G with n vertices, numbered from
1 to n.
For every pair of distinct vertices i, j with i > 1 and j > 1, the graph must satisfy the
following condition: after deleting vertices i and j, together with all edges that have
an endpoint at either vertex, exactly aij edges must remain.
Each pair of vertices i, j is considered separately. That is, for each pair, start with G before any vertices or
edges have been deleted.
It is guaranteed that at least one such graph exists. If there are multiple solutions, output any of them.

Input
The ﬁrst line contains an integer T (1 ≤ T ≤ 6 · 104 ), the number of test cases. The description of the test cases
follows.
For each test case, the ﬁrst line contains an integer n (4 ≤ n ≤ 103 ), denoting the number of vertices in the
graph.
Then each of the next n lines contains n space-separated integers aij (−1 ≤ aij ≤ (n−3)(n−2)
), representing the
2
matrix A described in the statement.
It is guaranteed that the total sum of n2 over all test cases does not exceed 1.2 · 106 , and that at least one graph
corresponding to matrix A exists.

Output
For each test case, output the adjacency matrix of the graph you construct. Output n lines, each containing n
space-separated integers. Each integer must be either 0 or 1. The entry in the i-th row and j-th column is 1 if
there is an edge between vertices i and j, and 0 otherwise. If there are multiple solutions, output any of them.
