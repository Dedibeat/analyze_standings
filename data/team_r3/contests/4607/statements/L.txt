L

Long Slides

Time limit: 2s

This problem has an attachment. You can use it to simulate and visualize
the movements of the robot.
VegiCat has a robot on an inﬁnite two-dimensional grid. He wants it to move from
cell s = (sx , sy ) to cell t = (tx , ty ). Each cell has integer coordinates. The cells s and
t may be the same.
The robot follows a string p of instructions. Each character is L, R, U, or D. Let |p|
denote the length of p.
The robot starts at s. Before it executes any instructions, you may place at most
|p| obstacles in distinct cells. The coordinates (x, y) of each obstacle must satisfy
−2 · 109 ≤ x, y ≤ 2 · 109 . Neither s nor t may contain an obstacle. Each obstacle occupies one cell and remains
ﬁxed throughout the process; all other cells are free of obstacles.
The robot executes the instructions p1 , p2 , . . . , p|p| in order. For each instruction, starting from its current cell
(x, y), it moves along the following sequence of cells:
• L: (x, y) → (x − 1, y) → (x − 2, y) → · · · ;
• R: (x, y) → (x + 1, y) → (x + 2, y) → · · · ;
• U: (x, y) → (x, y + 1) → (x, y + 2) → · · · ;
• D: (x, y) → (x, y − 1) → (x, y − 2) → · · · .
The robot repeatedly takes one step in the speciﬁed direction while the next cell contains no obstacle. It stops
in the cell immediately before the ﬁrst obstacle in that direction. If the next cell in the speciﬁed direction
already contains an obstacle before the instruction starts, the robot stays in place, but the instruction is still
completed. If there is no obstacle ahead in that direction, the robot would move forever, and the placement is
invalid.
The robot may reach t before all instructions are completed. It must still execute all remaining instructions.
Construct any obstacle placement satisfying the requirements above such that the robot ﬁnishes at t after the
last instruction, or report that no such placement exists.

Input
The ﬁrst line contains an integer T (1 ≤ T ≤ 105 ), the number of test cases. The description of the test cases
follows.
The ﬁrst line of each test case contains two integers sx and sy (−109 ≤ sx , sy ≤ 109 ), the coordinates of the
starting cell.
The second line contains two integers tx and ty (−109 ≤ tx , ty ≤ 109 ), the coordinates of the target cell.
The third line contains the instruction string p (1 ≤ |p| ≤ 105 ), consisting only of the characters L, R, U, and D.
It is guaranteed that the sum of |p| over all test cases does not exceed 105 .

Output
For each test case, output an answer in input order. Obstacle placements for diﬀerent test cases are independent.
If no valid placement exists, output NO on a line by itself.
Otherwise, output YES on the ﬁrst line. On the second line, output an integer k (0 ≤ k ≤ |p|), the number of
obstacles.
Then output k lines. The i-th of these lines must contain two integers xi and yi (−2 · 109 ≤ xi , yi ≤ 2 · 109 ),
specifying an obstacle in cell (xi , yi ).
All k coordinate pairs must be distinct, and none may equal s or t. The placement must allow every instruction
to ﬁnish and leave the robot at t after the last instruction. If there are multiple solutions, output any of them.
You can output the yes or no verdict in any case. For example, yEs, yes, Yes, and YES are all accepted as
positive responses.
