Given a string S = s0 s1 · · · sn−1 of length n, you can shift S to the left for at most k times (including
zero times). Calculate the maximum number of “nanjing” substrings contained in the string after the
operations.
More
formally,
let
f (S, d)
be
the
string
obtained
by
shifting
S
to
the
left
d
times.
That
is,
f (S, d)
=
s(d+0) mod n s(d+1) mod n · · · s(d+n−1) mod n .
Let
g(f (S, d), l, r) = s(d+l) mod n s(d+l+1) mod n · · · s(d+r) mod n . Let h(d) be the number of integer pairs
(l, r) such that 0 ≤ l ≤ r < n and g(f (S, d), l, r) = nanjing. Find an integer d such that 0 ≤ d ≤ k to
maximize h(d) and output this maximized value.

Input
There are multiple test cases. The first line of the input contains an integer T indicating the number of
test cases. For each test case:
The first line contains two integers n and k (1 ≤ n ≤ 2 × 105 , 0 ≤ k ≤ 109 ) indicating the length of the
string and the maximum number of left shifts you can perform.
The second line contains a string s0 s1 · · · sn−1 of length n. The string consists of lower-cased English
letters.
It’s guaranteed that the sum of n of all test cases will not exceed 5 × 105 .

Output
For each test case, output one line containing one integer, indicating the maximum number of “nanjing”
substrings contained in the string.

Example
standard input
4
21 10
jingicpcnanjingsuanan
21 0
jingicpcnanjingsuanan
21 3
nanjingnanjingnanjing
4 100
icpc

standard output
2
1
3
0

Note
For the first sample test case, we can shift the string to the left 6 times and get the string
“pcnanjingsuananjingic”. There are two “nanjing” substrings.
For the second sample test case, because k = 0, we cannot perform any left shifting. There is one “nanjing”
substring in the original string.
