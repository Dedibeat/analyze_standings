You have N Arcane Behemoths, each with an attack value Ai .
You may choose any non-empty subsequence of Behemoths and sell them one by one. Whenever you sell
a Behemoth, each remaining unsold Behemoth in the subsequence increases its attack value by the attack
value of the Behemoth you just sold.
The value of a subsequence is the maximum attack value the last remaining Behemoth can achieve, if the
other Behemoths in the subsequence are sold in an optimal order.
Your task is to compute the sum of values over all non-empty subsequences of the sequence. Print the
result modulo 998244353.

Input
The first line contains a single integer T (1 ≤ T ≤ 2 × 105 ) — the number of test cases.
For each test case, the first line contains an integer N (1 ≤ N ≤ 2 × 105 ) — the number of Behemoths.
The second line contains N integers A1 , A2 , . . . , AN (0 ≤ Ai < 998244353) — the initial attack values of
the Behemoths.
P
It is guaranteed that
N ≤ 2 × 105 over all test cases.

Output
For each test case, print a single integer — the sum of values over all non-empty subsequences modulo
998244353.

Example
standard input

Note
Consider the subsequences of [1, 2, 3]:
• [1] → only one Behemoth remains, value = 1.
• [2] → value = 2.
• [3] → value = 3.
• [1, 2]: sell the larger Behemoth 2 first, leave 1 → final attack = 1 + 2 = 3.
• [1, 3]: sell 3 first, leave 1 → final attack = 1 + 3 = 4.
• [2, 3]: sell 3 first, leave 2 → final attack = 2 + 3 = 5.
