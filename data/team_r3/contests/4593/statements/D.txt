Setsuna is studying music theory. There are n distinct pitches, numbered 1, 2, · · · , n. Setsuna wants to
compose a melody P in which every pitch appears exactly once. We call a sub-melody Q compact if and
only if there exist integers l ≤ r such that the set of pitches appearing in Q is exactly {l, l + 1, · · · , r}.
To compose the harmony, Setsuna specifies some requirements using two strings a, b, each of length n:
• For the sub-melody P [1, i] consisting of the first i pitches:
– If ai = 1, this sub-melody must be compact.
– If ai = 0, this sub-melody must not be compact.
– If ai = ?, there is no restriction on this sub-melody.
• For the sub-melody P [i, n] consisting of the last n + 1 − i pitches:
– If bi = 1, this sub-melody must be compact.
– If bi = 0, this sub-melody must not be compact.
– If bi = ?, there is no restriction on this sub-melody.
Before solving And Revive The Melody, Setsuna wants to find one melody that satisfies all the
requirements. You need to help Setsuna find any such melody, or report that no such melody exists.

Input
This problem contains multiple test cases.
The first line contains a positive integer T (1 ≤ T ≤ 104 ), representing the number of test cases.
For each test case:
• The first line contains an integer n (2 ≤ n ≤ 2 × 105 ).
• The next two lines each contain a string of length n, namely a and b.
It is guaranteed that the sum of n over all test cases does not exceed 2 × 105 , and that the strings contain
only the characters 1, 0, and ?.

Output
For each test case, output one line:
• If no solution exists, output the integer −1.
• Otherwise, output n integers P1 , P2 , · · · , Pn representing a valid answer.
