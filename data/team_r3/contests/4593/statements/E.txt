An intense dissatisfaction with the world,
and a compulsion to do something about it...
— Akira Complex, Ether Strike

Hikari has collected n glass shards, numbered from 1 to n. Each shard has 64 binary attributes. The k-th
bit describes the k-th attribute, so the attribute value of a shard is an integer in [0, 264 ).
Then, m events happen to the “world”. Each event is one of the following:
1. A fracture of the first type has its own attribute value x and affects every shard whose index is
in [l, r]. If an affected shard differs from the fracture in more than d attributes, it is forcibly
transformed into a shard with attribute value x.
2. Hikari needs to deal with the shards whose indices are in [l, r]. You need to tell her the sum of their
attribute values.
3. A fracture of the second type has its own attribute value x and affects every shard whose index is
in [l, r]. Every affected shard is forcibly transformed into a shard with attribute value x.

Input
The first line contains three integers n, m, d (1 ≤ n, m ≤ 2 × 105 , d = 3), representing the number of
shards, the number of events, and the attribute threshold, respectively.
The second line contains n integers ai (0 ≤ ai < 264 ), representing the initial attribute value of each
shard.
The next m lines each begin with an integer opt, representing the type of the event:
• If opt = 1, three more integers l, r, x follow (1 ≤ l ≤ r ≤ n, 0 ≤ x < 264 ), describing a fracture of
the first type.
• If opt = 2, two more integers l, r follow (1 ≤ l ≤ r ≤ n), describing a query from Hikari; since the
answer is large, you have to output it modulo 264 .
• If opt = 3, three more integers l, r, x follow (1 ≤ l ≤ r ≤ n, 0 ≤ x < 264 ), describing a fracture of
the second type.
It is guaranteed that at least one event has opt = 2.

Output
For each query from Hikari, output one line containing an integer representing the sum of the attribute
values modulo 264 .

For the first sample, let H = 263 , U = 264 − 1, and F = 15 · 260 .
• Initially, the sequence is [0, 7, 15, 56, H, U ].
• In the second event, the numbers of differing attributes are 0, 3, 4, 3, 1, 64, respectively. Since d = 3,
the sequence becomes [0, 7, 0, 56, H, 0].
• After the fourth event, the sequence is [0, U, U, U, U, 0].
• After the sixth event, the sequence is [F, F, F, F, U, 0].
• After the eighth event, the sequence is [F, F, U, U, U, U ].
• After the tenth event, the sequence is [1, 1, 1, U, U, U ].
Each query asks for the sum modulo 264 . In particular, the last answer is 0 because 3 + 3(264 − 1) = 3 · 264 .
