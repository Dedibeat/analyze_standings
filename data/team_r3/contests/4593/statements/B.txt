Milk has a tree with n nodes. Node i has a non-negative integer weight ai . Shama wants to destroy the
tree. She may perform one of the following three operations:
• Choose a node whose weight is 0 and whose degree is ≤ 1, then delete the node and its incident
edge, if any.
• Choose a node whose weight is nonzero and set ai ← ai − 1.

• Choose a node and set its weight to the MEX of the weights of all its neighboring nodes.
Shama wants to delete all nodes as quickly as possible. You need to help her find the minimum number
of operations required to achieve this goal.
Recall that the MEX of a set is the smallest non-negative integer that does not occur in the set.

Input
This problem contains multiple test cases.
The first line contains a positive integer T (1 ≤ T ≤ 2 × 104 ), representing the number of test cases.
For each test case:

• The first line contains an integer n (1 ≤ n ≤ 2 × 105 ).

• The next n − 1 lines each contain two integers ui , vi (1 ≤ ui , vi ≤ n), representing an edge of the
tree.
• The last line contains n integers ai (0 ≤ ai ≤ 109 ).
It is guaranteed that, in each test case, the given n − 1 edges form a tree, and that the sum of n over all
test cases does not exceed 2 × 105 .

Output

For each test case, output one line containing an integer representing the answer.
