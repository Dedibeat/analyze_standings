Vanessa has n memories about humanity, numbered 0, 1, · · · , n − 1, arranged in this order on a circle.
Vanessa divides them into m contiguous intervals, computes the sum Si of the elements in each interval,
and defines the weight of the division as the greatest common divisor of all the Si .

n
Through the Eye of Horus, Vanessa sees all m
possible divisions, but she cannot endure so many
memories. You need to help her calculate the product of the weights of all divisions. Since the answer
may be large, output it modulo 109 + 123.
Recall that a positive integer is a common divisor of a set S if and only if it divides every element of S.

Input
This problem contains multiple test cases.
The first line contains a positive integer T (1 ≤ T ≤ 100), representing the number of test cases.
For each test case, the only line contains two integers n, m (2 ≤ m ≤ n ≤ 1012 ).

Output
For each test case, output one line containing an integer representing the answer.

Note
For the first test case, the weights of all six divisions are listed below:
• gcd(0, 1 + 2 + 3) = 6
• gcd(0 + 1, 2 + 3) = 1
• gcd(0 + 1 + 2, 3) = 3
• gcd(1, 2 + 3 + 0) = 1
• gcd(1 + 2, 3 + 0) = 3
• gcd(2, 3 + 0 + 1) = 2
Therefore, the answer is 6 · 1 · 3 · 1 · 3 · 2 = 108.
