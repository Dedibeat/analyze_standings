Ritmo and Fisica are building a tuning device. A tuning device consists of a sequence a in which every
integer in 1 ∼ n occurs exactly twice, and a regular bracket sequence s containing n pairs of brackets.
A tuning device works correctly if and only if it satisfies the following conditions:
• Create one vertex for each index.
• For every pair of matching brackets whose indices in s are (li , ri ), add an edge between these two
vertices.
• For every value in a, let (xi , yi ) be the indices of its two occurrences, and add an edge between these
two vertices.
• The procedure above produces one cycle containing all 2n vertices and all 2n edges.
Ritmo has already installed a. Now you need to help Fisica find a corresponding sequence s. It can be
proven that such a regular bracket sequence always exists.
Recall that a bracket sequence is regular if and only if it can be constructed using the following rules:
• () is a regular bracket sequence.
• If A is a regular bracket sequence, then ( + A + ) is a regular bracket sequence.
• If A, B are regular bracket sequences, then A + B is a regular bracket sequence.

Input
This problem contains multiple test cases.
The first line contains a positive integer T (1 ≤ T ≤ 104 ), representing the number of test cases.
For each test case:
• The first line contains an integer n (2 ≤ n ≤ 2 × 105 ).
• The second line contains 2n integers ai (1 ≤ ai ≤ n).
It is guaranteed that the sum of n over all test cases does not exceed 2 × 105 , and that every integer in
1 ∼ n occurs exactly twice in a.

Output
For each test case, output a regular bracket sequence s of length 2n representing a valid answer.
