Give a strictly increasing sequence a of length n and a initial value v0 .
For all 0 ≤ v ′ ≤ v0 , find the number of permutations p of length n such that the following procedure
yields final value v = v ′ :
1. Initialize v ← v0 ;
2. For i = 1, 2, . . . , n, update v ← v mod api ;
Output the answer modulo 998244353.

Input
The first line contains two integers n and v0 (1 ≤ n < 218 , 1 ≤ v0 < 218 ).
The second line contains n integers a1 , a2 , . . . , an (1 ≤ a1 < a2 < · · · < an < 218 ).

Output
Output v0 + 1 integers, where the i-th integer (1 ≤ i ≤ v0 + 1) represents the answer for v ′ = i − 1, modulo
998244353.

Examples
standard input

standard output
