Construct a permutation p1 , p2 , · · · , pn of length n that satisfies lcm1≤i≤n pi + p(i mod n)+1 ≤ 20n.

Input
The first line contains a positive integer t (1 ≤ t ≤ 104 ), representing the number of test cases. Each
test case contains a single integer n (1 ≤ n ≤ 8 · 106 ), representing the length of the permutation. It is
guaranteed that the sum of n over all test cases does not exceed 8 · 106 .

Output
For each test case, output the permutation p1 , p2 , · · · , pn that satisfies the condition.
It is guaranteed that at least one such permutation exists.

Example
standard input
1
3

standard output
1 2 3

Note
In the example, lcm(p1 + p2 , p2 + p3 , p3 + p1 ) = lcm(3, 5, 4) = 60 ≤ 20n.
