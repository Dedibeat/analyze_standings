Problem F. Skill Activation Order

Dew writes a program to generate a skill activation order for a team in BanG Dream!. However, an off-by-one error prevents the program from inserting a removed member at the end of the list. The team consists of n members, numbered from 1 to n. Initially, the list is L = (1, 2, . . . , n). All indices in the list are 0-based. The program performs n iterations in order. In iteration i (0  i < n), it performs the following operations:
1. Remove the member x currently at index i from the list. 2. Choose an integer j satisfying 0  j  n - 2. Insert x into the shortened list so that its index becomes
j. The member previously at index j in the shortened list, and all subsequent members, are shifted one position to the right.
After each iteration, the list still contains n members. In particular, the removed member cannot be inserted at the end of the list. Given a permutation P , determine the number of integer sequences (j0, j1, . . . , jn-1) for which the final list is exactly P , where ji is the insertion index chosen in iteration i. Output the answer modulo 998 244 353. Two sequences are considered different if they differ in at least one insertion index.
Input
There are multiple test cases. The first line of the input contains an integer T (1  T  1 000), indicating the number of test cases. For each test case:

It is guaranteed that the sum of n over all test cases does not exceed 2 000.

Output

For each test case, output one line containing an integer, indicating the number of valid sequences modulo 998 244 353.
