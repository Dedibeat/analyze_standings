Problem H. Set of Intervals

Prof. Pang has a multi-set of intervals S = {[li , ri ]}(li < ri ).
Prof. Pang will perform the following operation for |S| − 1 times:
• Select two intervals [a, b] and [c, d] from S, and then choose two integers x, y satisfying
x ∈ [a, b], y ∈ [c, d], x < y. After that, delete [a, b] and [c, d] from S, and add [x, y] to S.
It’s easy to ﬁnd that S contains exactly one interval after the operations, and Prof. Pang will get the
interval as a gift.
Now Prof. Pang wants you to calculate how many diﬀerent intervals he can get.

Input
The ﬁrst line contains one integer T (1 ≤ T ≤ 104 ), the number of test cases.
For each test case, the ﬁrst line contains one integer n (1 ≤ n ≤ 105 ) — the size of S. Each of the following
n lines contains two integers li and ri (1 ≤ li < ri ≤ 109 ), describing the i-th interval in S.
It is guaranteed that the sum of n over all test cases is no more than 105 .

Output
For each test case, output one line containing the answer to Prof. Pang’s question.
